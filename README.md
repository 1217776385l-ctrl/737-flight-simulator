# 737-800 飞行模拟器 · made by LYU

第一人称波音 737-800 客机飞行模拟器：浏览器即玩（Three.js，零外部模型/音频文件，全部程序化生成）。

**在线游玩**：GitHub Pages 部署后访问 `https://<你的用户名>.github.io/<仓库名>/`

## 特性

- **第一人称 737 驾驶舱**：PFD/ND/EICAS/MCP/顶板/CDU 全部由仿真内核实时驱动，MCP/顶板/中央台可点击
- **14 条险情剧本**：鸟击双发失效、发动机火警、客舱释压、液压失效、起落架卡阻、燃油泄漏、皮托管堵塞、风切变……每条真实改变仿真状态且有正确处置路径（QRH 提示卡）
- **五种迫降结局**：水面/机腹/野外/跑道紧急落地，接地率-姿态-中线-存活率的可复现结算（同操作同分，全链路种子化）
- **5 座机场航线**：浦东式枢纽 / 林芝式高原峡谷 / 马德拉式海岛 / 旧金山式雾城 / 吉达式沙漠，两两组合
- **导航系统**：J 键导航卡 + 驾驶舱 CDU 双页（PROG/RTE），相位机带滞回不瞎报
- **新手指引**：K 操作指南、阶段化提示条、引导首飞、新手/行话双语 HUD（N 键）
- 音景：N1 随油门的引擎声、火警铃、超速 clacker、振杆器、GPWS 语音、副驾驶 V1/ROTATE 呼叫

## 运行

```bash
cd sim && ./start.sh    # → http://localhost:8173
```

## 测试

```bash
cd sim
node tests/kernel.test.mjs        # 内核 19 项数值验收
node tests/scenarios.test.mjs     # 险情与结算 19 项
```

## 操作（节选）

方向键=杆 · PgUp/PgDn=油门 · F/V=襟翼 · G=起落架 · B=刹车 · R=反推 · Ctrl+G=自动驾驶 · C=视角 · K=指南 · J=导航卡 · N=双语 · H=QRH · P=暂停
